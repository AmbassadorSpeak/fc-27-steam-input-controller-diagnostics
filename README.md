## 📁 How It Works — Troubleshooting Workflow

1. Check whether the controller responds in Windows game-controller settings outside the game.
2. In Steam, open EA SPORTS FC 27 > Properties > Controller, and try enabling Steam Input for the game.
3. Fully close Steam and EA App from the system tray, then start Steam and the game again.
4. Compare USB and Bluetooth input behavior for DualSense if custom mappings are ignored.
5. Temporarily close input remappers such as DS4Windows, reWASD and InputMapper to rule out duplicate controller handling.
6. Check whether the controller works both in menus and during a match before committing to a new configuration.

## 🛠️ Troubleshooting Notes

Steam Support and EA guidance may change with game updates; do not stack multiple remappers.

If nothing changes, describe the exact symptom, current game version, Windows build, driver version and the last successful launch or working configuration when requesting official support.
